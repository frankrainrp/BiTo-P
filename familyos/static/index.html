FamilyOS

A local-first household coordination platform.

This public edition contains the runnable API, domain services, database migrations and tests. The production application UI is distributed separately.

Try the sample workflow

From the repository root, run python examples/demo.py. It creates a temporary household, exercises member-scoped tasks and checks an unauthenticated request.
