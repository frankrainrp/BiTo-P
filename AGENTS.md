# Public showcase scope

Keep this repository independently runnable with synthetic data. It is an API-focused portfolio edition, not the household production checkout.

- Never copy private deployment records, production addresses, credentials, personal media or databases into this repository.
- Keep the default listener and Docker binding on loopback. Document the username-login limitation accurately.
- Do not import the separate production UI assets or fonts without confirmed distribution rights.
- Run the Python test suite and `python examples/demo.py` after behavior changes.
- Public CI verifies code and the image; it must not deploy to any private server.
- Keep documentation claims tied to code and reproducible tests.
